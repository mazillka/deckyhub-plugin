About DeckyHub

DeckyHub is a free, open-source plugin store for Decky Loader. It's a Decky Loader plugin that lets you find, install and update Decky plugins from Gaming Mode with your controller, including plugins that aren't on the official Decky store.

Who makes it

DeckyHub is made by Andrii Shevchuk-Yuhanets (mazillka) as an independent project. It isn't affiliated with Valve or the Decky Loader project. Its code is on GitHub under the GPL-3.0-or-later license.

Where the plugins come from

DeckyHub's plugin list lives in mazillka/deckyhub-registry. Plugins are suggested by users or found through two community catalogs, Decky Extended Plugins by beallio and Decky Plugins Explorer by SafetZahirovic, plus the registry's own search of GitHub. A person reviews every addition before it's listed. Each listed plugin needs a GitHub release with a plugin ZIP.

The Decky store download counts shown on plugin pages come from the Decky plugin store (plugins.deckbrew.xyz), the official Decky Loader store. Thanks to its maintainers.

Every plugin belongs to its own authors. DeckyHub doesn't review them for safety, own or endorse them, so each one installs at your own risk. To help you decide, DeckyHub shows the warnings from Decky Extended Plugins' security audit, scans every plugin ZIP with ClamAV and YARA, and links the same file's VirusTotal and MetaDefender results. Known issues lists every plugin with a warning.

How it's built

Most of DeckyHub's code was written with the help of AI tools (Claude and Codex). Every release is still tested on real hardware before it ships, its code is checked by GitHub CodeQL on every change, and each release ZIP is virus-scanned before it's published. What changed in each version is in the release notes.

How DeckyHub controls quality

DeckyHub installs software on your Deck, so every change, every release and every listed plugin goes through checks before it reaches you. All of it is open, in this repository and in mazillka/deckyhub-registry.

Every change, before it's merged. develop and main are protected: nothing is pushed to them directly, and a pull request merges only when these pass (the browser tests are skipped when a change touches only Markdown or the website's docs/ and promo/ folders):

Check What it covers
Backend tests (Python's built-in unittest) Downloads, SHA-256 checks, HTTPS-only redirects, the settings file, registry parsing, and the Desktop installer run as root against stand-ins
Frontend unit tests Version comparison, release-notes cleanup, the cache, and every language's placeholders
Browser tests (over a hundred Playwright tests in four parallel shards) DeckyHub's real UI in a Gaming Mode mock: browsing, installing, updating, virus scan reports, Skip this version, known issues, Settings and controller focus
Type check The whole TypeScript frontend (tsc)
CodeQL GitHub's security analysis of the Python and TypeScript code
Dependency review and Dependabot Dependencies with known vulnerabilities are flagged, and security updates arrive as pull requests

Every release. Pre-releases (-rc) come first, and a stable release is a reviewed pull request from develop into main. The release workflow refuses a tag that doesn't match package.json, runs every test again and builds the ZIP with a read-only token. The ZIP is scanned with ClamAV, VirusTotal and MetaDefender before it's published, and the Desktop installer right after; the verdicts go into the release notes and the badges at the top of this page. Before a stable release, it's tried on a real Steam Deck: devtools/deck/ deploys the build over Steam's debugger, drives Gaming Mode with the D-pad and takes screenshots.

Every listed plugin. Each change to the plugin list is checked against GitHub: the release and its ZIP exist, and entries don't clash. A ZIP whose version doesn't match its release tag is flagged so its author can fix it. Each plugin's newest ZIPs are scanned with ClamAV and YARA a few times a day, and checked by VirusTotal and MetaDefender (each gets the ZIP uploaded if it hasn't seen it yet), and Decky Extended Plugins' audit warnings show on its card. Every plugin's results are on its page on deckyhub.com, and Known issues lists every plugin with a finding. Scans and warnings inform and never block. The scans are signature-based: they only catch malware someone has already found and written a rule for, and malware can be built to get past them, so a clean scan isn't proof of safety. Only the Decky plugin store reviews plugins by hand; DeckyHub's checks are a step up from downloading a ZIP straight from GitHub, not a replacement for that review.

Safe by design. Nothing installs without your tap: Install, Update and Uninstall go through Decky Loader's own installer. Downloads are HTTPS only, from the selected repository's GitHub releases, with SHA-256 checked whenever GitHub publishes one. The backend uses only Python's standard library, so no third-party packages run on your Deck.

Performance

Measured on a real Steam Deck (Gaming Mode, DeckyHub 3.4.0-rc.24, 630 plugins listed), with node devtools/deck/perf.mjs: it opens each page for 15 seconds and counts the frames Steam drew slower than 50 ms, the browser's long tasks (over 50 ms) and the changes made to the page.

Page Slow frames Slowest frame Long tasks Page changes
Discover (all plugins) 1 183 ms 1 (138 ms) 20
Installed 1 133 ms 1 (98 ms) 22
Updates 1 84 ms 1 (69 ms) 23
Search 1 83 ms 1 (104 ms) 22
Settings 2 100 ms 1 (111 ms) 29
  • Opening a page costs one slow frame, when it first draws. About 900 frames are drawn in the 15 seconds, and the rest are on time.
  • Idle: no long tasks in 10 seconds with DeckyHub loaded and no page open.
  • The backend answers 7.2 seconds after a plugin reload, which is mostly Decky Loader restarting it, then get_settings in about 35 ms and get_apps in about 47 ms.
  • Size: the release ZIP is 16 MB, most of it the packages Remote Install needs. The plugin's own script is 474 KB (120 KB compressed).

Numbers vary with the Deck, its load and the network; run the script on yours to compare. These are one run each, not averages.

Privacy

DeckyHub has no account, analytics or telemetry, and sends nothing to its author. The deckyhub.com website does count visits (page views, country and browser type, without cookies) with Cloudflare Web Analytics; the plugin itself is completely clean: it counts and sends nothing. The plugin only connects to GitHub, plus any custom plugin list you add yourself. Your settings, your optional GitHub token and your logs stay on your device.

Supporting DeckyHub

DeckyHub is free and stays free: every feature works without paying, and nothing is locked behind a donation. If it helps you and you'd like to chip in, you can do it on Ko-fi or GitHub Sponsors. It is entirely optional.

What a donation is for: the author's time on maintenance and on testing every release on real hardware, and the deckyhub.com domain. The virus scans run on free tools and services with no subscription, so they don't depend on donations.

What it doesn't change: a donation doesn't buy a place in the plugin list or a better rank (plugins are ordered by downloads, stars, name or date, and no paid placement exists), doesn't influence the security checks and doesn't unlock features. DeckyHub has no ads, analytics or telemetry, and never sees who donates.

Not able or not wanting to donate? A star on GitHub, a bug report, a translation fix or a word to a friend also helps.
