About DeckyHub

DeckyHub is a free, open-source plugin store for the Steam Deck. It's a Decky Loader plugin that lets you find, install and update Decky plugins from Gaming Mode with your controller, including plugins that aren't on the official Decky store.

Who makes it

DeckyHub is made by Andrii Shevchuk-Yuhanets (mazillka) as an independent project. It isn't affiliated with Valve or the Decky Loader project. Its code is on GitHub under the GPL-3.0-or-later license.

Where the plugins come from

DeckyHub's plugin list lives in mazillka/deckyhub-registry. Plugins are suggested by users or found through two community catalogs, Decky Extended Plugins by beallio and Decky Plugins Explorer by SafetZahirovic, plus the registry's own search of GitHub. A person reviews every addition before it's listed. Each listed plugin needs a GitHub release with a plugin ZIP.

Every plugin belongs to its own authors. DeckyHub doesn't review them for safety, own or endorse them, so each one installs at your own risk. To help you decide, DeckyHub shows the warnings from Decky Extended Plugins' security audit, scans every plugin ZIP with ClamAV and YARA, and links the same file's VirusTotal and MetaDefender results. Known issues lists every plugin with a warning.

How it's built

Most of DeckyHub's code was written with the help of AI tools (Claude and Codex). Every release is still tested on real Steam Deck hardware before it ships, its code is checked by GitHub CodeQL on every change, and each release ZIP is virus-scanned before it's published. What changed in each version is in the release notes.

Privacy

DeckyHub has no account, analytics or telemetry, and sends nothing to its author. It only connects to GitHub, plus any custom plugin list you add yourself. Your settings, your optional GitHub token and your logs stay on your Deck.

Get involved

  • Contribute code or translations. DeckyHub comes in 17 languages, and corrections are welcome.
