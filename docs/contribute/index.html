Add a plugin to DeckyHub

The list behind DeckyHub's Discover tab lives here, in mazillka/deckyhub-registry. To browse the plugins, each with its own page, open the plugin list.

Browse all pluginsOpen the registry editor

Contribute

Changes land on develop first, then ship to main, which reaches every DeckyHub on its next restart. No app update needed.

Suggest a plugin

Know a Decky plugin that belongs here? Open an issue with its repository.

Add it yourself

Add an entry to registry/apps.json and its row in the README, then open a pull request. CI checks it against the plugin's real releases. How to add one

Run your own list

Fork this repository and add it in DeckyHub under Settings → Repositories → Custom Registries as owner/repo.

Registry editor

Prefer a bigger screen? Build or edit a plugin list in your browser and export it as a registry file. Host it anywhere over HTTPS and add it as a custom registry. Nothing is uploaded. Open the editor

Install at your own risk. DeckyHub only fetches releases from their authors' GitHub repositories. It doesn't make, review or vouch for these plugins and isn't responsible for anything they do to your device or data.
