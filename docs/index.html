Install in a minute

You need Decky Loader on your Steam Deck first.

  1. Download the latest DeckyHub-v*.zip from the Releases page.
  2. In Gaming Mode, open Quick Access → Decky → Developer.
  3. Choose Install Plugin from ZIP and pick the downloaded file.
  4. Open Quick Access → Decky → DeckyHub and start browsing.

Good to know

Does DeckyHub install things automatically?

Never. Download ZIP just saves a file to /home/deck/Downloads/deckyhub. One-tap Install, Update and Uninstall go through Decky Loader's own installer, which asks you to confirm first.

I hit a GitHub rate limit. What now?

Without a login GitHub allows 60 requests per hour. Add a personal access token (no scopes needed) in Settings → GitHub Access to raise that to 5,000. The token stays on your Deck and is only sent to api.github.com.

Why doesn't a new release show up right away?

Release info is cached for 30 minutes. Any "Check for Updates" or "Refresh" button skips the cache and asks GitHub directly.

How is DeckyHub made?

Most of the code was written with the help of AI tools (Claude and Codex). Every release is still tested on real Steam Deck hardware before it ships.
