Про DeckyHub

DeckyHub — безкоштовний магазин плагінів із відкритим кодом для Steam Deck. Це плагін Decky Loader, з яким можна знаходити, встановлювати й оновлювати плагіни Decky в ігровому режимі за допомогою геймпада, зокрема ті, яких немає в офіційному магазині Decky.

Хто його робить

DeckyHub робить Андрій Шевчук-Юганець (mazillka) як незалежний проєкт. Він не пов'язаний із Valve чи проєктом Decky Loader. Його код є на GitHub за ліцензією GPL-3.0-or-later.

Звідки беруться плагіни

Список плагінів DeckyHub зберігається в mazillka/deckyhub-registry. Плагіни пропонують користувачі або їх знаходять через два каталоги спільноти, Decky Extended Plugins від beallio і Decky Plugins Explorer від SafetZahirovic, а також через власний пошук реєстру на GitHub. Кожне додавання переглядає людина, перш ніж його внести до списку. Кожному плагіну в списку потрібен реліз на GitHub із ZIP плагіна.

Кожен плагін належить своїм авторам. DeckyHub не перевіряє їх на безпечність, не володіє ними й не схвалює їх, тож кожен встановлюється на ваш власний ризик. Щоб вам було легше вирішити, DeckyHub показує попередження з аудиту безпеки Decky Extended Plugins, перевіряє кожен ZIP плагіна антивірусом ClamAV і правилами YARA та дає посилання на результати VirusTotal і MetaDefender для того самого файлу. Відомі проблеми перелічують усі плагіни з попередженнями.

Як його створено

Більшість коду DeckyHub написано за допомогою інструментів ШІ (Claude і Codex). Проте кожен реліз тестують на справжньому Steam Deck до виходу, кожну зміну коду перевіряє GitHub CodeQL, а кожен ZIP релізу перевіряють на віруси до публікації. Що змінилося в кожній версії — у нотатках до релізів.

Приватність

DeckyHub не має облікових записів, аналітики чи телеметрії та нічого не надсилає авторові. Він з'єднується лише з GitHub і з власними списками плагінів, які ви додали самі. Налаштування, необов'язковий токен GitHub і журнали залишаються на вашому Deck.

Долучайтеся

  • Запропонуйте плагін для списку.
  • Повідомте про помилку або поділіться ідеєю. Можливо, відповідь уже є на сторінці довідки.
  • Долучайтеся до коду чи перекладів. DeckyHub доступний 17 мовами, і виправлення завжди вітаються.
